## 💻 Local Preview
To preview locally on your Mac:
```bash
# Option 1: Open directly in your browser
open portfolio/index.html

# Option 2: Run lightweight Python server
python3 -m http.server 3000 --directory portfolio
# Then open http://localhost:3000 in your browser

# Option 3: Using Node / npx serve
npx serve portfolio
```

## ⚡ 1-Minute Vercel Deployment
To deploy this portfolio directly to `https://sanathgowda.vercel.app`:

```bash
# 1. Install or run Vercel CLI
npx vercel portfolio

# 2. Follow the 3 prompts:
# - Set up and deploy? Yes
# - Which scope? (Select your personal account)
# - Link to existing project? No
# - Project name? sanathgowda
# - Directory? ./
```
Once deployed, Vercel gives you your live production URL: **`https://sanathgowda.vercel.app`**!
